## Base44 Dev Environment

This repo runs a **Docusaurus v3** documentation site via `docker-compose.base44.yml`.

- **Start**: `docker compose -f docker-compose.base44.yml up -d`
- **Preview**: port 3000 (Docusaurus dev server with live reload)
- **Node**: v22 (node:22 base image, deps installed on container startup via `npm install`)
- **Docs**: Markdown files in `docs/` appear in the sidebar automatically (autogenerated sidebars)
- **Config**: `docusaurus.config.js` — edit title, navbar, theme, etc. there
- **Site URL**: set `DOCUSAURUS_URL` to the deployed public site URL; local development falls back to `http://localhost:3000`
- **No external secrets required**
